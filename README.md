## Лабораторна робота №3 — каталог товарів

У `Lab03-Products` реалізовано список товарів за адресами `/products` та `/items`, перегляд товару, створення, редагування й видалення. Список можна фільтрувати через query string за назвою, категорією та діапазоном цін. Для відсутнього ID показується власна сторінка 404.

Адміністративний список доступний за `POST /users/index`, коли параметр `parameter` у тілі запиту має правильне значення. Значення не передається в URL; без нього сервер відповідає `401 Unauthorized`.

### Запуск

```powershell
cd Lab03-Products
dotnet run
```

Приклади сторінок:

- `/products/index?category=Drinks&maxPrice=10` — список із фільтрами.
- `/products/1` — інформація про товар.
- `/products/edit/1` — редагування товару.
- `/products/delete/1` — підтвердження видалення.
- `/products/create` або `/products/new` — створення товару.
