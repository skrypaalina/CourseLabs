## Лабораторна робота №2 — Views Practice

Проєкт `ViewsPractice` — це ASP.NET Core MVC-застосунок для практики Razor-синтаксису. Він містить домашню сторінку та сторінку Sprint Tasks із переходами до прикладів привітання за часом доби, списку продуктів, переліку супермаркетів, списку покупок і форми замовлення.

У роботі також використано модель-словник, HTML Helpers, partial view та сервіс часу, підключений через dependency injection.

### Запуск

Перейдіть у папку проєкту та запустіть застосунок:

```powershell
cd ViewsPractice
dotnet run
```

Відкрийте адресу, яку виведе `dotnet run`.

### Основні сторінки

- `/Home/Index` — головна сторінка.
- `/Home/SprintTasks` — навігація між завданнями.
- `/Home/Greetings` — привітання з використанням `DateTime` і умовної конструкції.
- `/Home/ProductInfo` — створення та виведення продуктів циклом у Razor.
- `/Home/SuperMarkets` — перелік супермаркетів із `ViewBag`.
- `/Home/ShoppingList` — словник покупок і partial view із часом для покупок.
- `/Home/ShoppingCart` — форма замовлення з GET і POST діями.

> Папки `OrderSystem` у поточній копії репозиторію ще немає; запис про неї збережено зі списку робіт.
